# Online Food Delivery System

Software Engineering Mini Project — SR University

## Folder Structure
- `/auth` — Member 1: User registration, login, role-based access, admin dashboard
- `/restaurant` — Member 2: Restaurant & menu management (CRUD)
- `/orders` — Member 3: Cart & order management
- `/payment` — Scrum Master: Payment gateway + delivery tracking + notifications
- `/database` — Shared schema (build this first, before other modules)

## Setup
1. Clone this repo
2. Each member works inside their assigned folder on their own branch
3. See CLAUDE.md for coding conventions used by Claude Code
